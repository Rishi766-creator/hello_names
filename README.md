# Hello Names App

A simple full-stack application that allows users to submit names from a React frontend and view them using an Express backend API.

---

## Tech Stack Used

- Frontend: React (Vite), JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Other: Fetch API, CORS

---


Open a terminal and run:

```bash
git clone https://github.com/Rishi766-creator/hello_names.git

## How to Run the Backend

  cd backend
  npm install
  npm run dev

  ---

## How to Run the Frontend

cd frontend
npm install
npm run dev

---


## Default Ports Used

- Backend runs on port **5000**
- Frontend runs on port **5173**

---




## Assumptions or Notes

- Names are stored in memory using a JavaScript array.
- No database or file storage is used.
- This project is intended for learning and practice purposes.
